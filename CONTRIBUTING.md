# Contributing

Thanks for your interest in contributing to Awesome Digital Signage.

## Submit a resource

The preferred way to suggest a new resource is through the **Submit a resource** issue form.

This allows contributors to suggest products, projects, tools, documentation, and other useful resources without creating a pull request.

Pull requests are also welcome.

## Submission requirements

Resources should:

- Be directly relevant to the digital signage ecosystem.
- Be active and publicly accessible.
- Have an official website, repository, or documentation page.
- Provide clear value to digital signage users, developers, operators, or integrators.
- Use a factual and neutral description.
- Be submitted only once.

Descriptions must not contain promotional language such as:

- Best
- Leading
- #1
- Revolutionary
- Ultimate
- Industry-leading

Commercial products are welcome.

If you are affiliated with the submitted resource, please disclose that affiliation.

## Review process

Submissions are reviewed manually.

Submission does not guarantee inclusion.

Maintainers may:

- Edit descriptions for clarity and consistency.
- Move resources to a more appropriate category.
- Request additional information.
- Decline submissions that do not meet the scope or quality requirements.
- Remove resources that become unavailable, abandoned, misleading, or no longer relevant.

Review times are not guaranteed.

## Pull requests

If you prefer to submit a pull request directly:

- Submit one resource per pull request.
- Add the resource to the most appropriate category.
- Follow the existing formatting.
- Use the official URL.
- Keep the description short, factual, and neutral.
- Avoid unrelated formatting changes.

## Reporting problems

Use the **Report a resource** issue form to report:

- Broken links
- Discontinued products or projects
- Outdated information
- Incorrect categories
- Duplicate entries
- Other problems with existing resources
